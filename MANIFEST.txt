CHẠY APP REACT (máy bạn)
  cd airline-ticket
  npm install
  npm run dev
  → http://localhost:5173

CHẠY PREVIEW HTML
  cd airline-ticket
  python3 preview_server.py
  → http://127.0.0.1:8765   (chỉ trên máy đang chạy server)

CHẠY API
  cd airline-ticket/server
  npm install
  npm start
  → http://localhost:3001
